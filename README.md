## 🚀 How to Deploy on Render (Free Static Site)

1. **Push to GitHub**:
   - Create a new repository on GitHub (e.g. `prime-portal` or `prime-study-abroad`).
   - Push these files to your repository.

2. **Deploy on Render**:
   - Go to [dashboard.render.com](https://dashboard.render.com).
   - Click **New +** > **Static Site**.
   - Connect your GitHub repository.
   - Settings:
     - **Name**: `prime-study-portal`
     - **Branch**: `main`
     - **Build Command**: *(leave blank)*
     - **Publish Directory**: `./`
   - Click **Create Static Site**.

Your website will be live in 30 seconds with a free custom SSL domain:
`https://prime-study-portal.onrender.com`
